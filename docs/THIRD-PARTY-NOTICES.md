# Сторонние компоненты

Исходный код приложения разработан для лабораторной работы. Сторонние компоненты сохраняют собственные условия использования.

- EmguCV 4.13.0.5924 поставляется через официальные NuGet-пакеты Emgu Corporation. Условия лицензии: https://www.emgu.com/wiki/index.php/Licensing . Копии метаданных и лицензий пакетов находятся в NuGet-кэше после восстановления.
- XML-каскады взяты из `opencv/opencv`, тег `4.13.0`, каталог `data/haarcascades`. Авторские уведомления и условия лицензий находятся внутри XML и должны сохраняться при копировании.
- `OpenCV-LICENSE.txt` — файл LICENSE того же тега OpenCV. Он не означает, что все изображения набора примеров имеют ту же лицензию.
- `samples/portrait.jpg` — `samples/data/lena.jpg` из OpenCV, стандартное тестовое изображение. Используется здесь только как учебный тест; отдельная лицензия на распространение фотографии этим проектом не предоставляется.
- `samples/two-faces.jpg` — коллаж двух копий этого портрета; `samples/demo.avi` — последовательность из 20 копий портрета с кодеком MJPG, 10 кадров/с. Это искусственные тестовые данные, а не запись с камеры.
